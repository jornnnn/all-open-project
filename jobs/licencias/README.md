# Plantillas de licencias

Textos oficiales de la [lista de licencias de SPDX](https://spdx.org/licenses/) 3.29.0, tal cual. El robot los compara con los archivos de licencia que GitHub no reconoce (ver `packages/core/src/licencias-texto.ts`).

Se generan con `pnpm --filter @aop/jobs run licencias`. No los edites a mano.
